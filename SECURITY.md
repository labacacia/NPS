# Security Policy

## Reporting

Use GitHub private vulnerability reporting: https://github.com/labacacia/NPS/security/advisories/new. Do not open a public issue. Include the affected version, reproduction conditions, and impact, with secrets and unrelated data removed.

Only the latest maintained branch and latest pre-release are supported unless maintainers state otherwise.

## Scope

Review Markdown, YAML, links, examples, and release metadata as untrusted content. This repository must not contain secrets or private implementation material.
