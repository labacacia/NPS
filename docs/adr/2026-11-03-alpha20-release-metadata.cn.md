# Alpha.20 发布元数据继承

日期：2026-11-03。状态：已接受，仅用于 #134 本地候选准备。

用户于 2026-11-03 授权可逆的 alpha.20 候选准备和本地预检。本决策仅允许
`spec/version-matrix.yaml` 顶层 `suite_version` 从 `1.0.0-alpha.19` 改为
`1.0.0-alpha.20`，不授权发布、标签、Actions，或功能、协议、契约、故障、阈值变更。

原始十二项工件冻结、清单和 `data_workflow_freeze_v1` 保持历史原始字节；现有
增量继承记录也保持原始字节。独立发布元数据记录绑定增量矩阵前驱哈希与当前哈希。
检查器仅还原唯一且完全匹配的顶层套件版本行，再要求字节匹配原增量矩阵哈希，
随后执行原冻结证明。没有新记录的旧检出仍走原路径；alpha.20 矩阵必须具有严格
新记录。刷新当前哈希不能授权其他矩阵编辑。本决策不表示可以打标签，也不证明
注册表权限或签名就绪。
