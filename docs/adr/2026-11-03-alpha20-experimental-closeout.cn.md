# ADR：以有边界的实验数据工作流候选收口 alpha.20

- 状态：用户于2026-11-03（Australia/Adelaide）接受。
- 授权原文：“按已验证实验范围收口 alpha.20，重审旧门槛，全量生产能力排后续（建议）”；并指示“暂时不用Github Actions，CI跑本地”。取代[范围提案](../plans/2026-11-03-alpha20-scope-decision-proposal.cn.md)中的待选状态。
- 追踪：Epic163、D20-00/08、既有129..134；补充[方向ADR](2026-10-19-alpha20-data-workflow-focus.md)。

## 范围与声明

alpha.20收口已验证实验：在模型上下文外完成正确、有界的数据工作，返回已授权
证据，明确失败和恢复。NWP/NIP结果HTTP仅覆盖.NET/Python公开结果客户端至.NET
参考服务端。NCP批次为显式启用的.NET原生参考；NOP为四个本地worker参考；NDP为
易失双节点参考。六SDK解析/错误辅助函数及回归仍属辅助函数/编解码证据，不宣称
完整结果/运行时互操作，不默认宣告特性。原生结果操作、其他SDK结果路径、远程
生产NOP、持久生产NDP、完整生产运行时/challenge profile、八产品采用均排后续。

保留NCP负面测量及普通工具/NPS工具80/80结果、精确源码和边界。alpha.20将旧的
普遍30%CGN/50%线路节省发布门槛调整为精确正确性、资源界限、公平独立对照和
真实测量声明。历史门槛及结果保留，不标为达成，不承诺普遍网络/token/耗时/费用
收益。广泛NCP移植延期；本决定满足方向ADR的测量后范围决定要求。

## 本地CI与发布边界

当前以本地CI为执行依据。验证工作流关闭push/PR/定时/仓库通知自动触发，保留
手动定义但不调用。使用本地runner及新的绑定源码日志/回执，远端旧结果作为历史
证据，不伪造远端检查状态，不要求GitHub Actions secrets。本地CI不调用模型API。

缺少Cargo token或GitHub secret不阻止编译、测试、审计和本地未发布打包。实际
发布权限、Maven签名、真实发布源码SourceLink、最终20版本物化/投影一致性及
有效发布候选回执仍是134在打tag/发布前的前置要求。本地未签名/非Git快照明确
标注。D08交付可复现、绑定源码的实验产物及真实134交接，不宣称ready-to-tag。
12项beta门槛和21天观察期仍单独处理、未验收、未豁免。本决定不授权tag、注册表
上传、Gitee写入或发布。

## 验证与完成

先冻结本决定/矩阵，再本地执行。必须包含六SDK回归及辅助契约、真实声明路径的
正负例、当前依赖审计、完整历史秘密扫描、版本/oracle一致、原始12份资产不变、
源码/包来源及已记录的基准/模型证据，不重跑已关闭付费对照。失败、精确源码、
工具链及测试产物均保留。只有当前实验AC通过且后续/发布义务有可追踪处置和交接，
D08/Epic163才完成；#134保持开放。
