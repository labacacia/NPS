## 目标与阅读路径

Agent 选择有界操作，运行时在模型上下文之外查询、计算和传递批量数据。
模型收到汇总、授权样本和结果引用，能按需追溯原始记录，并获知准确的执行状态。
模型成本、网络效率和可靠性分别测量。

先读本计划确定范围和验收，再读 ADR 理解决策，最后进入关联 Issue 查看实现证据。
初始授权为计划和追踪。2026-11-02 用户已授权按依赖顺序持续推进 Epic 实现。
当前状态与逐项 AC 证据以 Epic #163 及其子 Issue 为准；前置门禁和独立发布决策继续生效。

## 五协议分工与范围

| 协议 | 职责 | alpha.20 重点 |
| --- | --- | --- |
| NCP | 传输绑定 schema 的记录与变化 | 重复 schema 批量、流控、增量和重新同步 |
| NWP | 暴露数据与操作 | 查询/计算、结果资源生命周期、有界检查 |
| NIP | 绑定身份与受限权限 | 结果访问、委托、撤销和服务端策略所需的身份依据 |
| NDP | 解析可用端点与粗粒度能力 | 新鲜度、节点变化后的重新准入、状态所有权 |
| NOP | 组合操作并报告执行 | 授权结果交接、有界重试、取消与恢复 |

以 NWP 产品契约为主：先完成 NWP/NIP、测量 NCP、证明单节点流程，再进行 NOP/NDP
多节点验证。单节点样板支持静态端点，不强制部署完整发现设施。
规范仅在接受语义变更时升级，不为凑齐五协议而机械增加功能或版本。

优先复用既有帧和 Query/Action。新字段、操作名、feature ID、存储承诺与修订号必须经过
D20-00 决策及 #129 契约冻结。下表是语义要求，不是已注册 schema 或已实现 API。

| 概念 | 必须明确的语义 |
| --- | --- |
| 结果定位符与签发/服务节点 | 定位结果及服务权威；持有引用本身不授予权限 |
| schema 引用 | 标识结构，不能包含或替代数据内容 |
| 快照/版本 | 读取、派生计算和证据绑定同一数据状态 |
| 所有者与策略 | 身份/租户、允许操作、行列限制 |
| 总数与有界预览 | 元数据和样本也必须经过权限检查 |
| 过期与释放 | 保留、清理、重启语义和过期后的确定性失败 |
| 来源 | 追踪计算、原始记录与上游快照版本 |

schema AnchorFrame、负责集群路由的 Anchor Node、结果引用、模型供应商上下文/缓存 ID
是不同概念，不能互相替代。

## 样板任务与主流程

采用固定随机种子的合成订单/退款数据，大规模场景包含 100,000 条记录。
任务识别固定时间窗口内退款原因分组的异常增长，返回精确支持汇总，并允许授权下钻。
D20-00 冻结任务、异常规则、schema、标准答案、字段策略和证据预算。
这些是计划中的 fixture，不是现有能力声明。

```text
用户问题 → 模型选择有界查询/计算
         → NWP 通过 NIP 认证并检查资源/数据出口策略
         → 运行时查询、计算并保留版本绑定的结果
         → 必要时通过 NCP 传输批量/增量数据
         → 模型接收汇总、有界样本和结果定位符
         → 通过后续 NWP 检查回溯原始记录

后续：NOP 在 Worker 之间交接授权引用；
      NDP 解析端点，但端点替换不代表结果状态已复制。
```

批量中间结果默认保留在运行时，仅通过授权的有界检查进入模型上下文。
外部模型供应商是数据出口边界。工具返回是非可信数据，不能修改策略或权限。

## 不在范围内

- 修改模型权重、tokenizer 或供应商计费方式。
- 依据二进制传输、schema hash 或缓存 ID 承诺自动节省模型 token。
- 新建通用数据库、庞大查询语言或压缩格式。
- 为单节点样板强制全球发现、每步自主多 Agent 推理或全部 daemon 部署。
- 扩大 CA/HSM/声誉基础设施或默认开启 NIP Phase-3。
- 完整治理 challenge 产品交互或 beta 就绪声明。
- 恢复归档仓库，或把独立生命周期产品强制纳入发布列车。

## 测量与验收设计

| 路径 | 输入与执行方式 | 隔离的收益 |
| --- | --- | --- |
| A | 全量 JSON 记录进入模型上下文 | 直接上下文基线与超限失败 |
| B | schema 加位置行数组进入模型上下文 | 表达方式收益及准确率代价 |
| C | 普通 HTTP 工具在外部计算，返回有界证据 | 无 NCP 时的上下文路由收益 |
| D | 使用等价操作和证据的 NPS 流程 | NPS 额外的传输、互操作和恢复价值 |

C/D 使用相同数据源、计算逻辑、权限、可见证据和模型配置。
A/B 在可支持规模使用等价任务和数据；无法完整装入时记录上下文超限，
不得静默截断后作为同等任务计入。覆盖 100、1,000、100,000 行、
schema 变化和更新比例，并按预先确定的重复次数报告分布。

记录所有轮次供应商实际 input/output 及可观察的 reasoning/cache usage；
缺失字段保持未知。冷缓存、热缓存分列。网络字节在相同完整 framing 边界测量，
包含压缩和未压缩 HTTP 对照；另列内存、可观察 CPU、延迟分布、正确率及故障结果。
CGN/字节估算、确定性运行时观测和供应商 usage 是不同证据等级。
如报告实际费用，必须记录带日期的供应商费率和全部适用用量类别。

D20-00/01 在运行前确定重复次数、模型配置、正确率容差、资源/延迟预算和选型规则。
订单/聚合结果必须与精确 oracle 一致；模型结论和引用有明确评分标准。
不预设节省百分比。如果 D 相比 C 没有可测量收益，应公开结果并在大规模移植前
重新审查 NCP 范围，不能把 C 的收益归给 NCP，也不能事后偷偷更换成功标准。

现有 [CGN benchmark](../benchmarks/token-savings.md)采用字节估算和手写流量 fixture，
[context benchmark](../benchmarks/llm-context-savings.md)使用可观测的确定性运行时。
两者均不能证明供应商账单降低。D20-01 修正文档声明，并通过门禁对账记录处理
发布手册/CI 中历史固定收益阈值，不能静默删除门禁。

## 影响与不变量

- 架构：NWP 引入结果资源边界，存储、计算和供应商细节由运行时隔离；
  NCP 负责 framing，NIP 负责身份权限依据，NDP 负责发现，NOP 负责编排。
- 安全：逐次服务端授权、租户隔离、受限委托、元数据/聚合披露策略，
  以及已有和派生结果的撤销处理。仅持有身份不代表有资源权限。
- 数据：快照、来源、过期/释放、有界存储、明确的重启和故障转移保证；
  派生结果不能靠更换 ID 绕过源策略。
- 依赖：本计划不预选新存储、序列化库或模型供应商，需按契约和比较证据决定。
- 运维：背压、超时、取消、容量拒绝和如实报告不确定结果；
  重试 ID 不承诺外部副作用 exactly-once，取消不承诺回滚。
- 文档：规范双语、公共 API、样板、生命周期/支持声明、基准和发布手册同源更新。
- 信任边界：模型/工具输入 → 策略门禁 → 结果存储/计算 → Worker 或外部供应商。
  脱敏日志/证据保留标识、hash 和决策，不记录凭据或无必要载荷。

### D20-06：NOP 任务交接

复用 NOP outcome、重试和 `nps-runner`，跑通查询→分析→报告。
任务通过授权结果引用交接；明确输入、所有权和下游完成/过期后的清理。
支持普通代码或模型生成计划，不强制每步调用模型。
验证越权/过期输入、重复交付、响应丢失、重启、取消竞争、部分失败和迟到结果。
保留稳定操作身份、有界重试、真实去重保留承诺和三类执行确定性。
未知变更不得自动重放，下游不得消费未经证实的结果，取消不暗示副作用已回滚。
验收为有界可追溯 DAG 及真实失败结果；同步双语交接和恢复示例。

### D20-07：NDP 多节点

复用 NDP liveness/resolve、NWM、registry 和多节点样板。
发现粗粒度能力和端点，详细 schema 留在 NWP；节点变化重新协商/准入。
保留静态单节点路径，明确结果绑定原节点、共享存储恢复或不可用三种保证。
验证 stale/draining、伪造记录、过期能力、必需能力零派发拒绝、
epoch/sequence 回退、split-brain、issuer 丢失及接替节点无状态。
不能把端点接替当成状态复制，也不能静默重放变更。
验收要求多节点真实恢复/失败证据，单节点仍可独立运行；同步拓扑和部署说明。

### D20-08：资格与发布交接

通过既有 #129/#130/#131/#133 交付数据 profile 的向量、公共 API 和运行时证据，
避免重复 SDK 实现。六 SDK 对所有声称支持的共享能力完成适用 native/HTTP
混合版本矩阵；每格记录版本、binding、fixture hash、实际结果和零派发证据。
通过 #132 对账 adopter，独立产品不自动变成强制发布成员。
完成安全/故障、脱敏证据、残留风险、包 dry-run、源码/分发漂移和安全扫描。
unsupported/未执行不能计入通过；保留门禁缺证据则继续阻断。
同步双语迁移、支持/实验台账、API、样板和收益声明。
验收为经过验证的预发布交接，由 #134 负责发布及独立 beta 决策。

## 完成定义
