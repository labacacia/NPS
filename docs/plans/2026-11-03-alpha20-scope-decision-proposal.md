# Alpha.20 scope decision proposal after measurements

Status: resolved by explicit user acceptance on2026-11-03. [Accepted decision](../adr/2026-11-03-alpha20-experimental-closeout.md) and current ID-level ledger supersede the proposal status. The proposal text below is preserved as decision history.
D20-08/Epic163 remain IN_PROGRESS. Human scope input requested on2026-11-03 while
independent CI/package/handoff work continues. This is not a publication request.

The [accepted direction ADR](../adr/2026-10-19-alpha20-data-workflow-focus.md)
requires an explicit design/scope decision before broad porting when NCP supplies no
additional measured value over equivalent HTTP. The paired D04 runs found native
reference transport worse on wall/CPU/allocation/TLS bytes than matched HTTPgzip.
D05's ordinary tools and NPS tools both produced80/80 exact answers; no exclusive
NPS model-fee/token/latency advantage was established. Those negative results are
valid evidence, not grounds to silently erase the old30%CGN/50%wire gates.

## Proposed bounded experimental candidate

Keep six-SDK shared parsing/error contracts and ordinary regression coverage.
Claim only the supported experimental data paths in the [current support ledger](../qualification/2026-11-03-alpha20-support-ledger.json):
.NET/Python result HTTP clients to the .NET reference server; .NET host-bound NIP
result admission; opt-in .NET NCP batch reference; local NOP role reference and
volatile NDP two-node routing. Unimplemented SDKs/bindings and full production or
governed-challenge profiles stay unsupported/unqualified. No default advertisement.

Before using this narrower scope as a release basis, the original authorities must
record exact ID-level dispositions through the existing tracks:

| Obligations | Required recorded decision |
|---|---|
| A20-G01/G07; P20-001..009/401..409 (#132) | Bind inventory/individual owners; approve exclusions or later adoption with current independent/archived lifecycle boundaries |
| A20-G02/G04; P20-101..109 (#129) | Freeze only accepted claimed contracts/corpora; preserve unfinished production/runtime/challenge corpus as explicit later obligations |
| A20-G03/G05/G08; P20-201..208 (#130) | Declare features/SDKs/bindings and public error contracts; retain legacy compatibility; re-freeze required cells, preserving the576-cell historical unexecuted matrix |
| A20-G06; P20-301..306 (#131) | Truthful daemon/bridge manifests; no unsupported feature advertisement; deferred runtime integration stays unqualified |
| A20-G09; P20-501..509 (#133) | Bind fault/transport/soak applicability and exact evidence; no codec-only runtime passes or invented clean interval |
| Legacy30%CGN/50%wire gates | Replace or retain by explicit authority decision and defined baseline; proposal recommends measurement/correctness evidence without universal savings promises |
| A20-G10/G11/G12; P20-601..607 (#134) | Preserve security/authority/signing/source/version/drift checks; materialize coherent candidates only after scope is accepted; publication and beta remain separate |

Unexecuted or failed cells are never converted to passes. A later obligation keeps
its original ID and owner; experimental scoping requires a recorded adaptation or
deferral, not deletion. No binding adopter is silently removed. Required new-scope
runtime cells still need execution after the accepted matrix is frozen.

Alternative: retain the entire original six-SDK/native+HTTP production-contract,
adopter and qualification scope for alpha.20. This requires continuing all missing
implementations/evidence under the existing tasks and an explicit NCP scope decision
consistent with the measured negative result. Current scoped green tests do not
satisfy it. Neither route authorizes publishing or waives security/beta gates.
