## Status

NPS latest suite release is `v1.0.0-alpha.18`, published 2026-08-15. SDK install guidance remains aligned to alpha.18; the specification tree contains the reviewed, unreleased alpha.19 candidate. The first wave of production adopters is expected in Phase 3 (2027 Q1+). If you are evaluating NPS for a production use case, open a GitHub Discussion in the [NPS](https://github.com/labacacia/NPS) repository.
