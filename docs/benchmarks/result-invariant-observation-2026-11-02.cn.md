# 结果不变量的 HTTP 执行记录

日期：2026-11-02。对应 D20-02 #166 / D20-03 #167。本记录验证正确性和拒绝顺序，
不属于延迟测量、原生 NCP 验收或供应商计费证据。

`ResultFrozenInvariantHttpTests` 读取未变更的
[39 项冻结语义用例](../../spec/conformance/alpha20/data_result_vectors.json)，核对编码输入，
逐项断言预期结果和真实 ExecuteAsync 入口次数的增量；准备请求不计入该增量。
测试使用真实 ASP.NET HTTP 中间件、结果存储和实时资源策略，身份/摘要明确使用服务端
合成夹具。输入中的权限布尔值不会被反序列化成权限，也不会作为受信任调用者声明发送。

| 用例 | 实际服务状态与 HTTP 观察 |
| --- | --- |
| F01–F07 | feature 缺失/版本不符、服务关闭、路由撤回、未选择上下文的投影、未签名 Agent 头、验证器不可用，均不分发。 |
| F08–F16 | 所有者读取、其他租户/主体、来源撤回、精确到期和到期前一秒、释放、替换为空存储、另一未获证明的继任 issuer。 |
| F17–F23 | 快照/schema 替换、游标换列、limit 为 0/1001/布尔、实际捕获的单行大于页面预算。 |
| F24–F29 | 移除列权限、模型出站拒绝/允许、精确接收者授权、撤销、拒绝递归授权后第三方 HTTP 读取仍被拒绝。 |
| F30–F31 | 通过 read 拒绝 descriptor/预览披露，不支持的 `result.execute_sql` 返回规范 422。 |
| F32–F39 | 实际达到所有者 16 个结果上限、创建、同键内容冲突、精确 COUNT、所有者释放、未授权且快照错误/到期的读取、重复授权释放。 |

冻结文件是语义 oracle，并非序列化 ActionFrame。F30 的概念 `result.describe` 映射到
`result.read` 的 descriptor/预览表面，没有增加第五种线协议动作。抽象到期时刻 1000
映射到实际 300 秒 TTL（推进 300 或 299 秒），保持到期边界排他。重启用例实际替换
宿主/存储，不接受请求中自称的 issuer 状态。每次拒绝还检查响应不包含留存 locator/
快照、受保护列名或行数元数据；成功用例检查真实记录、计数总和和释放回执。

新增真实 mTLS 回归先复现了“未授权读取已进入 ExecuteAsync 才拒绝”的缺口。
入场现在预检实时权限、绑定和已知容量，不捕获、不释放、不预占、不消耗重放记录，
执行时仍保留实时/原子复检。独立 Kestrel mTLS/Ed25519/SQLite 用例验证资源和快照拒绝
零分发；接收者的已签名读取先被拒绝，补齐合法授权后，**同一投影**仍可成功，证明
此前的策略拒绝未消耗 projection ID。这不代表通用网关或生产 PKI 合格。接入边界见
[绑定 ADR](../adr/2026-11-02-result-invocation-http-binding.md) 和
[宿主说明](../../impl/dotnet/src/NPS.NIP/Invocation/README.cn.md)。

HTTP/结果/客户端/网关/中间件及既有原生锚点回归共 143 项通过，最终全量 1282 项全部通过。
初次全量为 1239/1240，通过项之外有一个既有原生锚点计时失败（1264 ms）；不改阈值的
独立复跑通过。冻结完整性、18 项契约测试、32 项离线 benchmark guard 同样通过。

预检增加了本地策略和有界页面工作。此前的
[HTTP 测量](runtime-http-observation-2026-11-02.cn.md) 仍只对应其记录的 `a4d80af`，
不能当作当前代码的性能证据。schema/更新负载及其余 Epic AC 继续独立跟踪。
