# DeepSeek 有界 C/D 证据观察

30 次有界证据回复全部精确符合冻结 JSON oracle，同一规模 C/D 的供应商输入/输出 token
完全相同。这支持在模型外精确计算后复述有界证据，不证明 NCP 专属模型 token 收益，
也不是模型主动规划的在线工具工作流。

[完整共享账本快照](runs/2026-11-02-deepseek-four-arm.json)保留 A/B 与 C/D、原始 usage、
合成可见答案、请求/来源/runner/提示词 hash 及费用记录。
[运行时证据](runtime-http-observation-2026-11-02.cn.md)记录实际先行 HTTP 工作流；
[方法](runtime-comparison-method-2026-11-02.cn.md)界定回放范围。

请求/返回模型均为 `deepseek-flash`；每规模/路径五次，temperature 0，关闭思考，输出
上限 2048，JSON 输出，无工具、重试或截断。C/D 收到完全相同的历史工具证据，包括
已算出的分组/异常谓词及有界真实来源记录/引用。机器 JSON 任务已有确定性运行时答案，
本身无需 LLM。来源引用在捕获时验证，回放前已经释放，不代表在线跟进会话。
system 指令/输出 schema 与 A/B 保持一致；C/D 前言说明显示行只是样例，计算分组覆盖全量。

| 行数 | A 完整 JSON：精确 / 输入 token | B schema+rows：精确 / 输入 token | C 普通工具：精确 / 输入→输出 | D NPS 工具：精确 / 输入→输出 |

每次重复均为表中 token 数，计入指令及引用文本。来源更大不意味着有界提示词 token
必然更多。被拒绝 A/B 的 usage 未知，不能填零；较小规模的已受理 A/B 答案也不正确，
因此不能计算“每个正确任务的费用比”。缓存计数按实际保留，不声称强制冷缓存；缺失
思考/缓存类别保持未知，只保存可见输出。

C/D 按峰值费率保守计算的 usage 上界为 $0.0197940；所有成功请求/探针上界合计
$0.1017384。此前十次未知 usage 失败仍保留 $3.20，累计共享记账上界 $3.3017384，
原 $10 cap 剩余 $6.6982616。这不是实际账单。2026-11-02 复核了
[官方费率与 alias 路由](https://api-docs.deepseek.com/quick_start/pricing/)。后续仍须复用
原本机 live ledger，本轮只扩展记录，没有重置预算，每次发送前均先预留费用。

解释：上下文缩减来自在模型外完成有限数据任务，再返回有界证据；普通 HTTP 同样能做。
当前 NPS HTTP 在该拓扑的字节/时延成本更高，结果语义、授权、溯源的价值应分别验收。
NCP 重复 schema 传输价值仍由 D20-04 验证。schema/更新工作负载、共享不变量、在线工具
编排、六 SDK 以及安全/发布门槛继续保留。
