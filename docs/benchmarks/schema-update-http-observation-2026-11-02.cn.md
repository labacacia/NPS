C 是直接 HTTPS；D 包含公共网关与接收端、每操作发现、新投影，以及当前每请求创建
的下游客户端。计数包含 D 两跳 TLS/HTTP 框架，不含 TCP/IP 包头，不能把拓扑差异
直接归因于原生 NCP 帧。两路径复用相同来源、存储和算子。
全部规模、冷/热及 identity/gzip 分布见[原始记录](runs/2026-11-02-schema-update-http-qualified.json)
和[摘要](runs/2026-11-02-schema-update-http-summary.json)。

为 null；计数/异常 ID 不变，退款金额按精确规则变化。旧页面/游标保留旧来源，新捕获绑定
新 schema/快照；无变化对照也拒绝其他结果的游标。重复测量时来源已固定，不代表切换
耗时、并发更新、插入/删除、delta 传播或实时流吞吐。
