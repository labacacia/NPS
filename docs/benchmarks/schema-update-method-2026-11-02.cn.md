# HTTP schema／更新负载扩展预注册方法

日期：2026-11-02。D20-01 #165，兼作 D20-02/03 的限定正确性证据。
先提交方法与夹具，再执行观察。不改 D20-00 冻结方法、种子、原始答案或历史观察。

执行 3 个规模 × 2 种 schema × 3 个更新比例 × 2 种连接状态 × 2 种响应压缩 × 2 条
HTTP 路径，共 144 项配置；每项预热 3 次、测量 30 次，共 4320 次测量、432 次预热。
维持每工作流 120 秒、全进程 RSS 512MiB、模型证据 32768 字节上限，以及既有
4 CPU／托管堆 320MiB 部署设置、真实 TLS 流字节边界、受支持的 NPS 客户端/双跳
网关和普通 HTTPS 同算子路径。无模型调用，不宣称原生 NCP、流/delta 效率或协议专属内存收益。

提交夹具并保持工作树干净后，运行（输出目录必须是尚不存在的绝对路径）：

```sh
python3 tools/benchmarks/data-workflow-changes.py --execute --output <new-absolute-observation-directory>
```

每个条件先从原始五列来源捕获旧结果/页面/游标。由操作员顺序切换来源：将前 N 个
稳定记录 ID 的 `amount_minor` 精确增加 100，N 为规模乘 0、0.01、0.1。记录 ID、顺序、
时段、原因、退款标记不变。`add-nullable-field` 条件为每行附加 `note: null`，并在
既有 FrameSchema 末尾增加 nullable string note；无其他变更。none/0 的来源版本仍为
`seed-20261102-immutable-v1`，其他条件为
`seed-20261102-update-{N}-nullable-{0|1}`；规模或条件变化会使来源缓存失效。
计时重复工作流使用切换后固定不变的来源，测的是变化后的新快照工作流，不测实时更新
吞吐、delta 传播或切换本身耗时。

计时前验证旧页面不变、旧游标继续旧快照；发生变化时新捕获必须换 snapshot，只有新增
nullable 列才换 schema。旧游标用于新捕获必须返回规范快照冲突。none/0 是无变化对照。
检查新首行金额及可选 null 列。计时后再次读取并释放旧结果。旧/新探测、引用来源准备和
清理的字节/时间均不计入测量工作流，并在记录中注明。

每次测量复用此前的 create/count/filter/aggregate/read/release 和相同算子、来源捕获授权、
模型出站策略。精确答案保留原始计数/异常/引用 ID，对每个被更新且已退款的记录，在对应
原因/时段退款金额中加 100。独立 Python 生成器/分析器重建更新后记录、fixture hash、
支持记录和答案；验证器要求 144 个唯一完整配置和 18 个真实 TRX 用例全部通过。
同条件 C/D 暴露逐字相同证据，新增 nullable 列包含在共同支持记录中。失败、日志、原始
观察全部保留，不能重命名为合格。

只改金额便于控制算术变量，不重定义冻结异常任务；不覆盖插入/删除/重排序、退款标记
变化或并发来源更新。已付费 A/B 仍只对应原始来源，不能当成扩展的供应商观察。
更广的传输或真实模型声明仍须对应证据和预算记录。

## 首轮失败保留及复测前诊断

01de64f 首轮实际执行 18 个条件，14 个通过、4 个失败，保留 124 项完整配置观察，见
[负面原始记录](runs/2026-11-02-schema-update-320m-attempt.json)。不能称为完整 144 项比较
或成功内存验收。其中一个明确在计算 hash 时将整份 fixture 转为 UTF-16，触发
OutOfMemoryException；另两个测量内 NPS 操作返回 500/NWP-NODE-UNAVAILABLE，还有
一个新建结果错误缺少详细状态。不能把这几个未分类错误直接归因为同一个内存问题。
完整日志/TRX 和失败均保留。

下一次干净提交复测前，改为逐行 UTF-8 流式 SHA-256，来源生成使用具名类型而非每行
dictionary，减少夹具额外分配，不删减结果操作或旧快照检查。额外只记录最后动作及
最多 64 个服务端异常类型名、最多四层因果；不格式化日志状态、异常正文/栈、scope 或
请求数据，隐私测试要求 formatter 从不调用。条件、次数、托管 320MiB／RSS 512MiB
门槛不变，不强制 GC。下一次提交/输出目录与来源记录必须独立。

C/D 同等使用该实现。精确 UTF-8 转义/数组字节边界、同快照/重放及失败不发布键的测试
保护语义。普通 HTTP 失败也经既有测量错误路径保留 HTTP 状态，不虚构协议码。
变更、次数、堆/RSS/延迟/证据门槛、旧快照检查和原始失败均保持。
