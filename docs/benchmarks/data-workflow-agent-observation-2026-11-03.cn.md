# 真实工具 Agent 实测 — 2026-11-03

普通 HTTP 和 NPS 各39/40个工作流返回精确答案与忠实引用。两次模型错误被拒绝、保留，没有修正成通过。
这证明有界工具工作流可用，不能证明 NPS 独有的 token、费用或延迟优势；普通 HTTP 同样能把计算留在模型外。

## 失败与生命周期

- NPS，100000/v1/cold/repeat1：聚合正确，但最终一条引用的 `schema_ref` 被模型抄短，精确引用校验拒绝。
- 普通HTTP，100000/v1/cold/repeat2：模型选择四个分时期过滤结果，最终返回原始group数组，未按要求给出嵌套答案/
  证据结构，最终校验拒绝；实际读取及释放仍完整记录。

两次均未静默修正、隐藏或重跑。宿主不信任模型生成引用，也不把无效结论变成成功。本次模型任务成功率97.5%，
不代表普遍可靠性。未来可用宿主维护的短引用避免模型抄长哈希，但属于新设计/测量，不能重分类本次失败。

每规模一次操作者更新：前1%金额加100并加入nullable note。检查时两份旧快照仍有效且原值不变，新snapshot/schema
改变；总金额增量100/100000符合规则。两条路径均完成更新后的精确答案与引用。默认三规模检查另验证错schema/
snapshot、直接绕过接收端、操作者/用户混淆、重复JSON及释放后访问均拒绝。未知分配/过期语义保留，没有第五种远程
result操作或原生result绑定。
