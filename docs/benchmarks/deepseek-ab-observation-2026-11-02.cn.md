# DeepSeek A/B 实测 — 2026-11-02

本轮按冻结的合成退款任务调用真实 API，未截断输入。100 和 1000 行共 20 次被模型接受的
A/B 调用，没有一次满足精确数字 oracle；100000 行的十次请求均因上下文长度被拒绝。
C/D 没有执行，因此没有证明 NPS 相比普通 HTTP 工具的额外价值。

## 配置与复现

固定 `deepseek-flash`、temperature 0、关闭 thinking、JSON 输出、最多 2048 输出 token。
每个规模和表示各五次，A/B 交替，任务、系统提示和来源一致，只改变对象 JSON 与
schema＋位置数组的表示。用户于 2026-11-02 授权两个模型名探测及本轮合计 10 美元上限。
两种请求模型名都返回 `deepseek-flash`。

## 实际结果

同一规模/表示的五次输入 token 数一致，含公共提示。延迟是客户端完整请求响应耗时，
不是 NCP 传输耗时；p95 按五个样本的 nearest rank 计算。

| 行数 | 表示 | 供应商输入 token | 精确答案 | 延迟中位数 / p95（ms） |
| --- | --- | ---: | ---: | ---: |
| 100 | A 完整对象 JSON | 3146 | 0/5 | 1951.034 / 2495.496 |
| 100 | B schema＋位置数组 | 1884 | 0/5 | 1910.186 / 2827.071 |
| 1000 | A 完整对象 JSON | 29246 | 0/5 | 2238.488 / 2741.554 |
| 1000 | B schema＋位置数组 | 16284 | 0/5 | 2054.354 / 2117.396 |
| 100000 | A 完整对象 JSON | 未知；上下文拒绝 | 0/5 | 6896.265 / 10174.299 |
| 100000 | B schema＋位置数组 | 未知；上下文拒绝 | 0/5 | 4117.591 / 6019.266 |

B 在 100 行时减少约 40.1% 输入 token，在 1000 行时减少约 44.3%。但两个表示在全部
被接受的请求里都有计数或求和错误。例如首个 A/100 答案给出 current delivery
13 单、退款金额 24576 最小货币单位，真实来源是 12 单和 23576。
只命中异常原因名称，不能算通过精确聚合验收。

这只代表当前关闭 thinking 的模型/配置/任务，不能推及所有模型。它提供了一个失败的
直接上下文基线，支持继续验证外部精确计算；不能拿来宣称 NCP 或 NPS 比普通工具更省。

## usage、缓存与费用

账本保留真实 usage 和合成可见答案。缓存命中由供应商计数观察，未强制清空其缓存。
cache-hit 是输入的子集，不可再与 prompt tokens 相加；未提供的 reasoning/cache
creation 类别仍未知。未测量完整 HTTP/TLS 线字节或运行时内存。

按[官方当日峰时 cache-miss 价格](https://api-docs.deepseek.com/quick_start/pricing/)保守
计算，20 次成功响应的费用上界合计 0.0819372 美元，探测另计 0.0000072 美元。
这不是账单。十次拒绝没有 usage，账本继续保留 3.20 美元预留，不假定免费。
合计保守占用 3.2819444 美元，剩余至少 6.7180556 美元预算，待未知费用核对后可释放。
成功响应上界未享受实际缓存或非峰时折扣。
